## 🚀 How to Use This Repository

1. Clone the repository:

```bash
git clone https://github.com/SoumitriRoy05/LEETCODE_SQL.git
```

2. Open the repository:

```bash
cd LEETCODE_SQL
```

3. Navigate to the `LEETCODE` folder.

4. Choose a problem based on its difficulty or topic.

5. Try solving the problem yourself before checking the solution.

6. Run and test the query on **LeetCode** or another compatible SQL environment.
